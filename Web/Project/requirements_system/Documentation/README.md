# Система за управление на изисквания  
**Версия: release 2.10**

---

## 1. Описание на проекта

Този проект представлява уеб система за управление на **проекти и функционалности (изисквания)** със йерархична структура.  
В системата **няма отделен елемент „requirement“** – **функционалността е самото изискване**.

Основната идея е:
- всеки **проект** да съдържа множество функционалности;
- функционалностите да са подредени в **йерархия (дърво)**:
  - Проект → Слой → Функционалност → Подфункционалност → …
- да се проследява **статусът** на всяка функционалност;
- да се поддържат и **нефункционални индикатори** (как се измерва дадено изискване).

Системата позволява:
- регистрация и вход на потребители;
- създаване и редактиране на проекти;
- добавяне на функционалности към проект;
- йерархия между функционалностите чрез родител–дете;
- качване на снимка към функционалност;
- проследяване на статус (не е започната / в процес / завършена);
- преглед и филтриране по проект;
- импорт и експорт на проект с функционалности;
- визуализация на проекта като **PlantUML MindMap**.

Проектът е реализиран с **HTML, CSS, JavaScript, PHP и MySQL**, без външни библиотеки.

## 3. База данни (основни таблици)

- **users**  
  `(id, username, password, created_at)`

- **projects**  
  `(id, name, description, created_at)`

- **requirements** (функционалности)
  `(id, project_id, title, description, layer, priority, importance, status, parent_id, assigned_to, image_path, created_at)`

- **indicators**  
  `(id, requirement_id, name, description, unit, value)`

- **tags**  
  `(id, requirement_id, tag)`

- **features**  
  `(id, name, description, status)`

> `parent_id` реализира йерархията между функционалностите.

## 5. Импорт и експорт

### 5.1. Импорт (import.php)

Импортът създава **нов проект** и **йерархия от функционалности** от текстов файл.

- Поддържани формати: `.txt`, `.csv`
- Йерархията се задава чрез отстъпление (таб или интервали)
- Грешка в данните прекъсва импорта

### Пример:
Моят проект
Описание на проекта
Функция 1;Описание;business;;ivan;IN_PROGRESS;
Подфункция;Описание;business;;;NOT_IMPLEMENTED;

---

### 5.2. Експорт (export.php)

- CSV файл с всички функционалности на проект
- PlantUML MindMap диаграма

Пример:
@startmindmap
Проект
** Слой
*** Функционалност
**** Подфункционалност
@endmindmap

## 7. Стартиране на проекта

1. Копирайте проекта в:
   `C:\xampp\htdocs\requirements_system`

2. Стартирайте Apache и MySQL от XAMPP

3. Импортирайте `sql/database.sql` в phpMyAdmin

4. Проверете настройките в `classes/Database.php`

5. Отворете:
   `http://localhost/requirements_system/PHP/index.php`
